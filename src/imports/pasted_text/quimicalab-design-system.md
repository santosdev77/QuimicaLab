Crie o design completo de uma plataforma web educacional de Química para estudantes do Ensino Médio, com foco em aprendizado interativo da Tabela Periódica.

O nome provisório do projeto é "QuímicaLab".

OBJETIVO:
Criar uma experiência moderna, intuitiva, visual e interativa que ajude estudantes a aprender Química de forma mais fácil e interessante. O site deve parecer uma plataforma educacional moderna, e não apenas uma tabela periódica online.

PÚBLICO:
Estudantes do Ensino Médio, aproximadamente 14 a 18 anos.

ESTILO VISUAL:
- Design moderno e tecnológico
- Visual de laboratório científico
- Interface limpa e organizada
- Profissional, mas jovem e atrativa
- Não utilizar aparência infantil
- Usar bastante espaço em branco
- Cards com bordas arredondadas
- Ícones simples e modernos
- Microinterações e elementos que transmitam interatividade
- Tipografia moderna e muito legível
- Contraste adequado
- Design responsivo para desktop, tablet e celular

PALETA:
Utilizar azul como cor principal, com tons de azul claro, branco e cinza.
Usar cores secundárias para representar diferentes famílias da Tabela Periódica.
Evitar excesso de cores na interface.

PÁGINA INICIAL:
Criar uma homepage com:

1. HEADER
- Logo "QuímicaLab"
- Menu:
  Início
  Tabela Periódica
  Aprenda
  Laboratório
  Desafios
- Botão "Começar a estudar"
- Ícone/avatar do usuário

2. HERO
Título grande:
"Descubra a Química de um jeito diferente."

Subtítulo:
"Explore os elementos, monte átomos, faça desafios e aprenda Química de forma interativa."

Adicionar dois botões:
"Explorar Tabela Periódica"
"Começar desafio"

Ao lado do texto, mostrar uma representação visual moderna de um átomo com elétrons orbitando, partículas e elementos químicos.

3. SEÇÃO "EXPLORE A TABELA PERIÓDICA"
Mostrar uma prévia da Tabela Periódica com os elementos organizados corretamente.

Cada elemento deve ser representado por um card contendo:
- Número atômico
- Símbolo
- Nome
- Massa atômica

Criar interação visual de hover nos elementos.

Adicionar filtros:
- Metais
- Ametais
- Gases nobres
- Halogênios
- Metais alcalinos
- Metais alcalino-terrosos
- Metais de transição
- Lantanídeos
- Actinídeos

Adicionar barra de pesquisa:
"Pesquise um elemento..."

4. SEÇÃO "APRENDA NA PRÁTICA"
Criar cards para diferentes conteúdos:

Estrutura Atômica
"Entenda prótons, nêutrons e elétrons."

Distribuição Eletrônica
"Descubra como os elétrons se distribuem."

Ligações Químicas
"Aprenda como os átomos se conectam."

Propriedades Periódicas
"Entenda raio atômico, eletronegatividade e outras propriedades."

5. SEÇÃO "LABORATÓRIO VIRTUAL"
Criar uma área visualmente mais tecnológica.

Cards:
"Monte um Átomo"
"Forme um Íon"
"Monte uma Molécula"

Mostrar uma prévia visual de um átomo interativo.

6. SEÇÃO "DESAFIE SEUS CONHECIMENTOS"
Criar uma área de gamificação.

Mostrar:
- XP
- Nível
- Sequência de dias
- Questões respondidas
- Acertos

Criar um card de exemplo:

"Qual elemento possui número atômico 8?"

A) Carbono
B) Oxigênio
C) Nitrogênio
D) Flúor

Mostrar uma interface de resposta moderna.

7. SEÇÃO DE PROGRESSO
Criar um dashboard mostrando:

Nível atual
XP
Progresso de aprendizado
Conteúdos concluídos
Taxa de acertos
Sequência de estudos

Adicionar uma barra de progresso.

8. CONQUISTAS
Criar badges modernos:

"Mestre dos Elementos"
"Conhecedor da Tabela"
"10 Desafios"
"Primeiro Experimento"
"100 Questões"

9. FOOTER
Links:
Sobre o projeto
Conteúdos
Tabela Periódica
Contato
Política de privacidade

EXPERIÊNCIA DO USUÁRIO:

O estudante deve sentir que está explorando uma plataforma, não lendo uma apostila.

Priorizar:
- Interatividade
- Visualização
- Gamificação
- Feedback imediato
- Navegação simples
- Hierarquia visual clara

Criar componentes reutilizáveis e manter consistência visual em todas as telas.

Criar o design pensando em uma futura implementação em React/Next.js e Tailwind CSS.

Organizar o projeto no Figma com:
- Design System
- Cores
- Tipografia
- Botões
- Cards
- Inputs
- Badges
- Navegação
- Componentes da Tabela Periódica
- Estados de hover, ativo, selecionado, erro e sucesso

Criar um protótipo navegável entre as principais telas.
